        Sources
        
    Where codes come from
    
        
    Sources only suggest codes. Every one is checked with SHiFT before anything is redeemed.
    
        
    
      
    
      
    
        
    1Built-in sources
    
        
    Community feeds, official announcements, guides and deal sites. Turn off any you don't want.
    
        
    
        
    
          
    Unsure Off by default
    
          
    Code sites we couldn't check when they were added, because they block automated visits from our test setup. They may work fine from your computer. Turn one on to try it; if it shows an error, it's blocking visits from apps too. Either way, SHiFT checks every code before anything is redeemed.

    Game launching
    
            
    SHiFT sometimes stops accepting codes until a SHiFT-enabled game has been started. This handles it for you.
    
            
    
            
    
            
    
              
              
            
    
            
    It closes as soon as SHiFT accepts codes again, usually well before this.
    
            
            
            
            
            
            
    In the Epic launcher, right-click a Borderlands game → Manage → Desktop shortcut. Then right-click the shortcut → Properties and copy the URL.
    
            
    Steam shows the 2K launcher first for some games? In Steam, right-click the game → Properties → Launch options, type -NoLauncher, and it starts straight away.
    
            
    
            
    The game opens briefly and closes as soon as SHiFT is ready.
    
          
    

          
    
            
    Pace
    
            
    How long to wait between requests to SHiFT. Going gently keeps Gearbox's servers happy and makes pauses less likely.
    
            
            
    !
    That's quite fastUnder 10 seconds puts more load on SHiFT, and SHiFT is more likely to pause you. Consider 10 seconds or more, or turn on smart pace.
    
            
            
    
            
            
    The minimum is 3 seconds and can't be lowered.

    ⚠ Save your password without encryption?
    
          
    
          
    If you continue, your SHiFT password will be saved as readable text in . That means:
    
          
      
            
    • Anyone who can use this computer account can open the file and read it.
      • 
            
    • Any program running as you, including malware, can read it.
      • 
            
    • Backups or cloud-synced folders may copy it somewhere else.
      • 
          
    
          
    If you continue, make sure your SHiFT password isn't used for anything else. Or don't save it: you're still signed in now, and you'll just need to sign in again when SHiFT's session expires (auto-pilot waits until you do).
